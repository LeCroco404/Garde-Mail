Confidentialité

Garde-Mail est conçu pour ne rien savoir de vous. Voici exactement ce qui se passe quand vous l'utilisez.

Ce qui reste dans votre navigateur

Les en-têtes, les messages et les mots de passe que vous saisissez sont analysés par le code de la page, directement sur votre appareil. Ils ne sont ni envoyés à un serveur, ni enregistrés : fermer ou recharger la page les efface.

Le site n'utilise ni compte, ni cookie, ni stockage local, ni outil de mesure d'audience. Le correcteur orthographique est désactivé dans les champs, car certains correcteurs envoient le texte saisi à un serveur pour l'analyser.

Les deux seules informations qui peuvent sortir

Elles ne partent que si vous lancez l'action correspondante, sans cookie et sans indiquer de quelle page vient la demande.

Vous cliquez sur « Consulter le DNS » (Ce mail est-il authentique ?) Le nom de domaine de l'expéditeur, par exemple example.com. Jamais le contenu du mail. Cloudflare, ou Google en secours (service DNS-over-HTTPS)
Vous vérifiez un mot de passe (Mes données ont-elles fuité ?) Les 5 premiers caractères de son empreinte SHA-1, par exemple 5BAA6. Jamais le mot de passe, ni l'empreinte complète. Pwned Passwords (api.pwnedpasswords.com)

Une règle imposée par le navigateur

Le site envoie à votre navigateur une politique de sécurité du contenu (CSP) : la liste des seules adresses vers lesquelles la page a le droit d'envoyer des données. Ce sont les trois services ci-dessus. Toute autre tentative est bloquée par le navigateur lui-même, même en cas d'erreur dans le code.

Vous pouvez le vérifier : ouvrez les outils de développement de votre navigateur (touche F12, ou Cmd+Option+I sur Mac), onglet « Réseau », puis utilisez un outil. Seules les requêtes décrites ici apparaissent.

L'hébergement

Le site est hébergé par Netlify. Comme tout hébergeur, Netlify reçoit techniquement votre adresse IP et le nom de la page demandée quand vous chargez le site. Garde-Mail n'y ajoute aucun outil de suivi.

Les liens vers d'autres sites

Les liens vers signal-spam.fr, Have I Been Pwned ou les sources officielles vous font quitter Garde-Mail : ces sites appliquent leurs propres règles. Garde-Mail ne leur indique pas que vous venez de ses pages.

Le code est public

Tout le code du site est consultable sur GitHub, y compris la politique de sécurité (fichier netlify.toml).

Garde-Mail aide à décider quoi faire d'un message suspect, mais ne garantit rien. En cas de doute, contactez l'organisme concerné par ses coordonnées habituelles.
