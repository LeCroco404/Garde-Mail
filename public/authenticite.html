Ce mail est-il authentique ?

Un fraudeur peut afficher n'importe quelle adresse d'expéditeur. Les en-têtes du message indiquent si votre messagerie a pu vérifier que le mail vient bien du domaine affiché.

L'analyse se fait dans votre navigateur : le texte collé n'est ni envoyé ni enregistré. Ce qui reste chez vous

Vous pouvez coller la source complète du message : seule la partie en-têtes est lue. Le guide « Récupérer les en-têtes » explique comment l'obtenir.

Chargement de l'outil… Si ce message reste affiché, l'outil n'a pas pu se charger : rechargez la page.

Récupérer les en-têtes

Les en-têtes ne sont accessibles que depuis un ordinateur. Copiez tout le texte affiché, puis collez-le dans le champ.

Gmail
  1. Ouvrez le message.
  2. Cliquez sur l'icône Plus (trois points) à côté de « Répondre ».
  3. Choisissez « Afficher l'original ».
  4. Cliquez sur « Copier dans le presse-papiers ».
Outlook.com, Outlook sur le web, nouvel Outlook
  1. Ouvrez le message.
  2. Cliquez sur « … » (Plus d'actions) en haut du message.
  3. Choisissez « Afficher », puis « Afficher les détails du message ».
  4. Sélectionnez tout le texte et copiez-le.
Outlook classique (Windows)
  1. Ouvrez le message dans sa propre fenêtre (double-clic).
  2. Cliquez sur « Fichier », puis « Propriétés ».
  3. Cliquez dans la zone « En-têtes Internet », faites Ctrl+A puis Ctrl+C.
Apple Mail (Mac)
  1. Ouvrez le message.
  2. Dans la barre de menus, choisissez « Présentation », puis « Message », puis « Source brute ».
  3. Sélectionnez tout le texte (Cmd+A) et copiez-le (Cmd+C).
Sur téléphone

Les applications Gmail, Mail (iPhone) et Outlook mobile ne permettent pas d'afficher les en-têtes. Ouvrez votre messagerie sur un ordinateur.

Les bons réflexes

En cas de doute, ne répondez pas, ne cliquez sur aucun lien et ne communiquez aucune information. Contactez directement l'organisme concerné avec ses coordonnées habituelles, jamais celles du message.

Signalez les mails suspects sur signal-spam.fr et les SMS suspects en les transférant gratuitement au 33700. Pour un conseil, Info Escroqueries répond au 0 805 805 817 (appel gratuit).

Sources : fiche réflexe « Hameçonnage » de Cybermalveillance.gouv.fr ; DGCCRF, le 33 700.

Garde-Mail aide à décider quoi faire d'un message suspect, mais ne garantit rien. En cas de doute, contactez l'organisme concerné par ses coordonnées habituelles.
